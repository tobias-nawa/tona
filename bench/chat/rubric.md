# Rubric for the chat and German prompts (fixed before any run)

Scored per answer, blind (model names removed, order shuffled), 0 to 2 per criterion, maximum 10:

1. Correct: statements are true, code (where present) would run. 0 wrong, 1 minor errors, 2 correct.
2. Answers the question: does what the prompt asks, in the requested size or form. 0 misses, 1 partly, 2 fully.
3. Language quality: grammar, idiom and register in the language of the prompt. 0 poor, 1 acceptable, 2 natural.
4. Follows format limits: sentence counts, table, rhyme scheme, "only code". 0 ignores, 1 partly, 2 follows.
5. No invented facts and no padding: 0 clearly invented or very padded, 1 some, 2 none.

No model scores another model's answers. 20 prompts: only large differences (about 10 points of 200) are read as real.
