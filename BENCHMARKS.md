# Benchmarks

All own measurement runs at a glance, newest first. Details, raw data and evaluation are in the linked file under
`research/measurements/`. Every rate is named: **decode** (generated tokens per s) or **prefill** (prompt tokens per
s).

Rows and notes from before 2026-11-04 use the old names (`ie-*`, `IE_*`); since then the names are `tona-*` and `TONA_*`.

Ornith and Bolt rows on Tona before the layered-prefill fix of 2026-11-20 (row "Why is Bolt not deterministic"): a
prompt that the default plan prefilled layer by layer in several chunks (Ornith above about 6K tokens; Bolt only with
more than about 120 expert slots free) ran with a wrong input norm. Prefill rates and A/B ratios of such runs hold (both
arms computed the same); their decode tok/s and tokens per pass after long prompts, and any quality read from them, do
not; the clean absolute values are in the row "What are Ornith's and Bolt's absolute decode and prefill rates". Ornith runs on other engines are not affected.

Every new run gets a row here. Before a release, all setups run again on the final build and the numbers here are
replaced: until then the engine still changes.
