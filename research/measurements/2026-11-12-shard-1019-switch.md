### 4. Speed baseline (`ab.py`, mid and long, deterministic, 3 rounds)

Report: `2026-11-12-shard-1019-switch-logs/ab-switch.md` (and `.json`); build `v0.0.2-490-gb6dd58cd44` (this branch),
arm A the old shard with `experts-coder-0929.bin`, arm B the new shard with `experts-coder.bin`, alternating AB, BA, AB,
warm-up of A first, port 8099. Round 2 is flagged "outlier" by `ab.py` (see below) but nothing was dropped.

| Rate | Old (median of 3, range) | New (median of 3, range) | B vs A, mean [95 % interval] | Against the plan |
|---|---|---|---|---|
| Prefill tok/s, 30K prompt | 1892.4 (1878.3-1893.4) | 1884.8 (1884.5-1891.6) | -0.05 % [-0.33, +0.23], equal | inside (+-0.1 %) |
| Decode tok/s, after 30K prompt | 66.1 (66.0-66.7) | 72.9 (72.2-73.2) | **+9.74 % [+9.07, +10.41]**, B faster | inside (+6..+10 %) |
| Prefill tok/s, 130K prompt | 1753.4 (1747.2-1755.3) | 1749.6 (1748.9-1755.2) | -0.04 % [-0.19, +0.11], equal | inside (+-0.1 %) |
| Decode tok/s, after 130K prompt | 63.9 (63.8-64.4) | 64.7 (63.4-64.9) | +0.49 % [-0.57, +1.56], undecided | inside (+-1 %) |

Round values, B vs A: prefill 30K +0.33 / -0.40 / -0.09 %, decode 30K +9.09 / +10.45 / +9.70 %, prefill 130K +0.14 /
-0.26 / -0.00 %, decode 130K -0.64 / +1.60 / +0.53 %. Round 2 (BA) is the "outlier" of the tool (more than four sd of
the table from the median of the rest and outside the expected range); with three rounds the per-round spread of
the paired difference is 0.3 to 0.9 % at 30K prefill and 130K decode, wider than the table (sd 0.04 and 0.42 %). This
is a finding: the order effect of one BA round is larger than the table on this day. It does not change a verdict.

**SHAs.** Arm A reproduces the old references of `bench/sha.toml` (`5b4e7ef2b0fc2495`, `9340252c318b7217`), stable over
3 rounds: the build and the old shard still give the old tokens. Arm B (new shard) is stable over 3 rounds too:
30000 `ee58880d3f5b558f`, 130000 `7d2996546076d1b0`. These are the new values of `bench/sha.toml`. The tool's warning
"texts differ from the reference of main" is the expected consequence of the switch.

**Expert cache** (counts per request, `/status`): 30K request, A 75602 / 75706 / 75706 hits and 6927 / 6823 / 6823
misses; B 70386 / 70386 / 70476 hits, 7308 / 7308 / 7218 misses. 130K: A 72219 / 72351 / 72351 hits, 7691 / 7559 / 7559
misses; B 77516 / 77516 / 77626 hits, 6497 / 6497 / 6387 misses. Counts differ slightly between rounds on each arm

(7.2 to 7.3 K against 6.8 to 6.9 K) and fewer at 130K (6.4 to 6.5 K against 7.6 to 7.7 K).

**Finding (absolute level):** the prefill rate at 130K is 1750 to 1755 tok/s on both arms here; the run of the morning
(`2026-11-12-coder-1019.md`, build 8f43a6b, 4 rounds) had 1789 on both. The difference between the arms is the same
(-0.04 %), so the comparison holds, but the absolute level is 2 % lower than yesterday's on both arms. The builds
differ (8f43a6b against b6dd58c, source-identical engine code), the cause is unchecked; the 30K prefill is equal to
yesterday's (1892 against 1886 old). A later run with `work/build/engine` in the same session would separate build
from machine state.
